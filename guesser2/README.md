# GeoGuesser2 專案

## 專案內容簡介
本專案是一個基於 Python Flask 框架開發的地圖地理位置猜測遊戲。系統會隨機產生目標地點，玩家需在地圖上標記並猜測其位置，系統隨後會計算實際距離並給予相對應的遊戲分數與統計總結。

## 執行方式
1. **安裝必要套件**：
   ```bash
   pip install -r requirements.txt
   ```
2. **啟動主程式**：
   ```bash
   python app.py
   ```
3. **瀏覽遊戲**：
   開啟瀏覽器並造訪 `http://127.0.0.1:5000` 即可開始遊戲。

## 主要檔案用途說明
* **app.py**：專案的主程式與 Flask 後端路由控制器。
* **game_setting.py / data_setting.py**：負責遊戲初始化、核心規則與資料處理的設定。
* **random_point.py**：負責隨機挑選或生成地圖上的目標地點。
* **calculate_distance.py**：利用經緯度計算玩家猜測點與目標點之間的實際距離。
* **scoring.py**：根據計算出的距離，轉換為玩家得分的計分機制。
* **route.py**：處理路徑規劃、導航或點對點之間的路線邏輯。
* **search.py**：處理地點搜尋或關鍵字比對功能。
* **reverse.py**：處理逆向地理編碼（經緯度轉地址）的輔助邏輯。
* **summary.py**：負責結算遊戲、統計分數與匯總玩家戰績。
* **test.py**：用於後端功能與邏輯的單元測試指令碼。
